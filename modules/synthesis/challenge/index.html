Tune to the brief

Three jobs. Set the four sliders so each one lands inside the range the job needs, then lock it in. Mistakes cost time in timed mode.

  1. Extract invoice totals as JSON for an accounting system.

    Exact output wants low randomness, tight constraints and a precise ask.

  2. Brainstorm twenty product names for a student startup.

    Variety wants more randomness and looser limits.

  3. Summarize a 40-page policy document for a board memo.

    A long source needs deep context and steady, moderately strict output.
