Glossary and resources

Adversarial example
An input altered in a small, deliberate way to make a model produce a wrong output.
Algorithm
A finite sequence of well-defined steps that turns an input into an output.
Artificial intelligence
Software that performs tasks usually associated with human judgment, such as recognizing speech or ranking results.
Backpropagation
The method that computes how much each weight contributed to the error, so gradient descent knows which way to adjust it.
Bias (in AI)
A systematic difference in how a model treats people or cases, usually inherited from unrepresentative data or past decisions.
Chain-of-thought prompting
Asking a model to write out intermediate reasoning steps before its final answer.
Context window
The maximum number of tokens a model can consider in a single pass.
Data leakage
Private or proprietary information escaping through a model, either from memorized training data or from sensitive input sent to an outside tool.
Differential privacy
A training technique that limits how much any single record can influence the model, and so how much it can reveal.
Feature
A measurable property of an example that a model takes as input, such as a pixel value or a word count.
Few-shot prompting
Including a handful of worked input-output examples in the prompt so the model continues the pattern.
Gradient descent
An optimization method that repeatedly nudges weights in the direction that reduces the loss.
Hallucination
Fluent model output that states something false, such as an invented citation or number.
Inference
Using a trained model, with frozen weights, to make a prediction on new input.
Loss function
A formula that scores how far a model's predictions are from the correct answers.
Machine learning
Building a function from labelled examples instead of hand-written rules.
Model card
A short document describing a model's intended use, evaluation results and known limitations.
Neural network
A model made of layers of simple units that each compute a weighted sum followed by a nonlinear function.
Overfitting
When a model memorizes its training examples and performs much worse on new data.
Parameter (weight)
A learned number inside a model. Training adjusts the parameters; inference reads them.
Prompt
The text given to a language model that begins the sequence it will continue.
Prompt injection
Hidden instructions in untrusted content that try to override a model's intended behaviour.
Red teaming
Having testers deliberately attack a system to find failures before release.
Temperature
A sampling setting. Low values make a model pick likely tokens almost every time; high values add variety and risk.
Token
A chunk of text, often a word or part of a word, that a language model reads and writes.
Training
The phase where a model's weights are adjusted to reduce the loss over many examples.
