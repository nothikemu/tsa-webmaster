Ethics knowledge check

Five questions. Score 4 to count toward the badge. The scored version needs JavaScript.

  1. What did the Gender Shades audit show about a single overall accuracy number?

    • It is the best measure of fairness.
    • It can hide large differences between groups.
    • It is always lower than per-group accuracy.
    • It predicts privacy risk.
    Show the answer

    It can hide large differences between groups.

    Overall accuracy averaged away a gap of 34.7% against 0.8% between groups.

  2. Differential privacy aims to:

    • Speed up inference
    • Limit how much any one individual's record can influence the model
    • Encrypt the model file
    • Increase accuracy
    Show the answer

    Limit how much any one individual's record can influence the model

    It bounds the influence of any single record, which limits what the model can reveal about it.

  3. Which defense is specific to prompt injection?

    • Separate trusted instructions from untrusted content
    • Increase image resolution
    • Add more training epochs
    • Set temperature to 0
    Show the answer

    Separate trusted instructions from untrusted content

    Keeping instructions apart from untrusted content stops the content from acting as instructions.

  4. A user is told an AI screened their application and is given a route to appeal to a person. This practices:

    • Transparency and recourse
    • Overfitting
    • Data augmentation
    • Prompt engineering
    Show the answer

    Transparency and recourse

    Disclosing automation and offering a human appeal are core transparency practices.

  5. Which is part of accountability?

    • A named owner and a rollback trigger
    • A bigger model
    • A faster GPU
    • Hiding the logs
    Show the answer

    A named owner and a rollback trigger

    Ownership and predefined rollback triggers make responsibility concrete.
