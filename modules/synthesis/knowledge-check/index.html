Synthesis knowledge check

Five questions. Score 4 to count toward the badge. The scored version needs JavaScript.

  1. What does the context window limit?

    • How fast the model replies
    • How many tokens the model can consider at once
    • How many users can connect
    • Which languages it supports
    Show the answer

    How many tokens the model can consider at once

    The window is the number of tokens the model can read and use in one pass.

  2. Which prompt contains a role, a task and a checkable constraint?

    • Summarize this.
    • You are a nurse educator. Explain insulin to a 9th grader in four sentences.
    • Write something good about insulin.
    • Insulin?
    Show the answer

    You are a nurse educator. Explain insulin to a 9th grader in four sentences.

    It names a role, a task, an audience and a sentence count.

  3. Few-shot prompting steers a model by:

    • Updating its weights
    • Adding worked examples to the prompt
    • Making the model larger
    • Lowering the temperature
    Show the answer

    Adding worked examples to the prompt

    The examples sit in the prompt. The weights stay the same.

  4. What does chain-of-thought prompting ask the model to do?

    • Search the web
    • Write out intermediate reasoning steps
    • Answer in one word
    • Repeat the prompt back
    Show the answer

    Write out intermediate reasoning steps

    The model writes its intermediate steps before the final answer.

  5. What is the best first step when evaluating output for a repeated task?

    • Read it once and approve it
    • Write acceptance criteria and a small test set
    • Raise the temperature
    • Shorten the prompt
    Show the answer

    Write acceptance criteria and a small test set

    Criteria and a test set make results comparable from one prompt version to the next.
