# Originality and credits

## What was written for this project

- All page copy, lesson text, quiz and challenge content, glossary entries, and UI strings.
- All imagery: there is none beyond vector art. The three badges (`src/assets/badges/*.svg`), the favicon, the flag, the realm posters and every chart are authored in this repository. They are drawn by an ink engine (`src/ui/Ink.tsx`: seeded variable-width brush strokes, hatching, rough-edge filters) rather than by hand with a pen; the badges were generated by a script that used the same approach and then committed as plain SVG.
- All 3D geometry: the layered particle topology (`modules/ModuleA/topology.ts`) and the icosphere (`modules/ModuleC/icosphere.ts`) are generated by code in this repository.
- All shaders except the noise function noted below: `src/gpu/glsl/*`, `src/gpu/wgsl/*`, `src/gpu/tsl/*`.
- The Rust crate `crates/core` (SHA-256, HMAC, ChaCha20, Perlin noise, spatial hash, particle integrator). Test vectors for SHA-256, HMAC and ChaCha20 come from the public standards (FIPS 180-4, RFC 4231, RFC 8439) and were cross-checked against OpenSSL.
- The gamification engine, persistence, integrity layers, router, spring solver, master loop, quality governor and build plugins.

No stock photography, video, audio or icon packs are used. Four open-licensed typefaces are bundled and served from this site, Latin subset only: Pirata One (display, SIL OFL 1.1), Big Shoulders Display (labels and numerals, SIL OFL 1.1), Barlow (text, SIL OFL 1.1) and Special Elite (captions, Apache 2.0). They are installed as the `@fontsource` packages, listed below and on `/credits`; no request leaves the site for them. If a face must go, delete `src/styles/fonts.css` and the package, and the system stack named after it in `tokens.css` takes over.

## Visual references

The visual direction is a manga page with a tactical interface laid over it, inspired by the VALORANT interface, One Piece and Death Note, as described (with the thin evidence behind it) in [DESIGN_RESEARCH.md](DESIGN_RESEARCH.md). What was taken is general technique and mood: flat angular panels, uppercase condensed labels, a navy, off-white and red palette; dense inked line, wanted posters, sea charts and a skull flag; black-and-white contrast, hatching, ledger rules and a single red accent. No artwork, logo, character, name, typeface, screenshot, color file or layout from any game, series or publisher is used, and nothing was traced. The flag, the realm posters, the badges, the mark and every other illustration are authored from scratch in this repository, and several are built from the learner's own saved state. The skull-and-crossbones is a generic pirate emblem, not any series' mark. The word "Wanted" on the badges is a generic poster heading.
