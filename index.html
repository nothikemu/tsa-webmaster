Three modules. Three different ways to touch an idea.

MOD 01 / FOUNDATIONS

Foundations

Rules write the program. Examples write the model.

Explain how a machine learning system differs from hand-written rules, name the parts of a neural network, and tell training apart from inference.

MOD 02 / SYNTHESIS

Synthesis

A prompt is a specification. Write it so it can be tested.

Write prompts that state a role, task, constraints and examples; explain what temperature changes; and judge an output against a checklist.

MOD 03 / ETHICS

Ethics

Every model fails somewhere. Responsible teams know where.

Identify four classes of AI risk, match each to a mitigation, and describe what accountability looks like for a deployed system.

Points for finishing, not for refreshing.

XP is paid once per step: 10 for seeing a lesson, 15 for practicing it, 25 for mastering it. A knowledge check pays only for improvement. After 400 XP in one day the rate drops to a quarter.

A streak counts days when you learned something, not days you opened the tab. Each module ends in a badge, and a badge needs a lesson set, a centerpiece, a 4-of-5 check and a cleared challenge.

Built like a product, shipped as static files.

1 WebAssembly module. Rust kernels for neighbour search, noise and hashing, with a TypeScript twin for every one.

5 compute paths. WebGPU compute, WebGL2 float textures, a WASM worker, WASM on the main thread, plain TypeScript.

60 frames per second target. A quality governor trades particle count and effects for frame time, never the other way round.

Built for TSA Webmaster 2026-2027. All progress stays on your device.
