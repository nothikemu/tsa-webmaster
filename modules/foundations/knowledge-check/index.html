Foundations knowledge check

Five questions. Score 4 to count toward the badge. The scored version needs JavaScript.

  1. Which statement about today's AI systems is most accurate?

    • They are general-purpose and understand context like people.
    • They are mostly narrow: built and tested for specific tasks.
    • They always improve with use.
    • They cannot make mistakes on familiar inputs.
    Show the answer

    They are mostly narrow: built and tested for specific tasks.

    Current systems are narrow. Each is built, trained and scored for particular tasks.

  2. What is the main difference between a rule-based program and a machine learning model?

    • Rule-based programs are always slower.
    • In machine learning, examples determine the logic instead of a person writing it.
    • Machine learning never needs data.
    • Rule-based programs use neural networks.
    Show the answer

    In machine learning, examples determine the logic instead of a person writing it.

    Rules are written by people. A learned model derives its behaviour from examples.

  3. In a neural network, what are the weights?

    • The number of layers
    • Learned numbers that scale each connection's signal
    • The training dataset
    • The output labels
    Show the answer

    Learned numbers that scale each connection's signal

    Weights scale the signal on each connection. Training adjusts them.

  4. Which step changes a model's weights?

    • Inference
    • Deployment
    • Training
    • Prompting
    Show the answer

    Training

    Training updates the weights. Inference only reads them.

  5. A hiring model trained mostly on résumés from one demographic performs worse on others. Which data problem is this?

    • Overfitting to noise
    • Unrepresentative training data
    • Too many features
    • Slow inference
    Show the answer

    Unrepresentative training data

    The training data did not cover the people the model is later used on.
